La lista está en orden alfabético, por apellido, con una letra para cada grupo. El buscador mira nombres, teléfonos, correos, direcciones y notas.

## La ficha

Cada contacto puede tener nombre, apellido, varios teléfonos y correos con su etiqueta, dirección, cumpleaños, notas y una **foto** (una imagen de tus carpetas). Todo se guarda automáticamente mientras lo escribes.

Para borrar un contacto se pide confirmación. Un contacto nuevo que se queda vacío no se guarda.
