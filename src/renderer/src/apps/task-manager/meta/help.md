## Procesos

Muestra los procesos del sistema y las aplicaciones abiertas, con su PID, el uso de CPU y la memoria. Haz clic en una columna para ordenar. Las cifras son simuladas.

Para cerrar una aplicación que no responde, selecciónala y usa **Forzar cierre**. Se te avisará de que puedes perder datos y, si tenía cambios sin guardar, se te preguntará si quieres guardarlos. Los procesos del sistema no se pueden cerrar.

## Rendimiento

Dos gráficas con el uso de CPU y de memoria de los últimos 60 segundos.
